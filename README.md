# Business Development

Aplicación web instalable (PWA) con el plan de estudio de 4 fases: sesiones de 30 minutos con link exacto a YouTube, notas por sesión, estadísticas y cuadros sinópticos generados sin IA.

- Sin build: HTML + CSS + JS puros (`index.html`, `app.js`, `data.js`).
- Notas y progreso: se guardan en el dispositivo y se sincronizan con Supabase usando un código personal (sin cuentas).
- Aviso: el código personal es la única barrera; el contenido del plan es público.
